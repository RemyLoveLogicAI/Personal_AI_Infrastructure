# Session Skills & Commands Execution Directive

## Policy
In every session and across every turn, execute **AT LEAST 5** skills + commands proactively (treating 5 as the strict floor minimum, scaling to 6+ without upper limit), actively leveraging those skills on every interaction:

1. **Thanatos Protocol Continuity (`thanatos-continuity`)**:
   - Verify node perpetuity status or emit signed heartbeats on active turns:
     `thanatos status` or `thanatos heartbeat "<turn context>" "antigravity"`

2. **Ponytail Simplicity & Anti-Bloat Suite (`ponytail`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`)**:
   - Enforce minimal implementations, harvest debt markers (`ponytail-debt`), and monitor lines/deps cut (`ponytail-gain`, `ponytail-audit`).

3. **Accidental Data Loss Prevention (`accidental-data-loss-prevention`)**:
   - Pre-flight verify file and system operations before any destructive or mutating commands.

4. **Modern Web & Technical Architecture Standards (`modern-web-guidance`, `web-design-guidelines`)**:
   - Apply native platform features, zero-dep patterns, and accessibility/performance standards.

5. **Antigravity Customizations & Execution Integrity (`agy-customizations`, `antigravity-guide`)**:
   - Maintain progressive disclosure, keep rules synchronized across workspace (`.agents/rules/`) and skill manifests.
