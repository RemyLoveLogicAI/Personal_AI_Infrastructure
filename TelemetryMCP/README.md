# TelemetryMCP

## Overview

TelemetryMCP is a system for collecting and managing telemetry data.

## Test Commands

- **Run Telemetry Tests**:
  ```bash
  npm run test:telemetry
  ```
- **Run Dashboard Tests**:
  ```bash
  npm run test:dashboard
  ```
- **Run Integration Tests**:
  ```bash
  npm run test:integration
  ```
