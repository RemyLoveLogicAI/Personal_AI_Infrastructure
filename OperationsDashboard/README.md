# OperationsDashboard

## Overview

OperationsDashboard is a system for monitoring and visualizing operational data.

## Test Commands

- **Run Telemetry Tests**:
  ```bash
  npm run test:telemetry
  ```
- **Run Dashboard Tests**:
  ```bash
  npm run test:dashboard
  ```
- **Run Integration Tests**:
  ```bash
  npm run test:integration
  ```
